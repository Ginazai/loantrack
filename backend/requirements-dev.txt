# Dev/CI tooling for the backend. Installed by CI *in addition to* the app itself:
#     pip install -e . -r requirements-dev.txt
#
# Why this file exists: pyproject.toml is Poetry-format, so `pip install -e ".[dev]"`
# silently installs nothing from the dev group ("does not provide the extra 'dev'")
# and ruff/mypy/pytest are never installed. Pinned to the versions this pipeline
# was validated with, so a surprise tool release can't turn CI red on its own.
# Dependabot (pip ecosystem) keeps these current.
